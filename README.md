# Прогнозирование оттока клиентов банка (Банковский скоринг)

Реализация сквозного аналитического пайплайна: от выгрузки сырых данных из базы через SQL до построения предсказательной модели логистической регрессии на Python.

## 📌 Описание проекта
Цель проекта — выявить ключевые факторы, влияющие на отток клиентов банка (churn), и построить математическую модель, способную предсказывать вероятность ухода клиента на основе его демографических данных и транзакционной активности.

Проект имитирует реальную бизнес-задачу аналитика данных в банковском секторе (на примере метрик Т-Банка).

---

## 🛠️ Стек технологий
* **Базы данных:** SQL (SQLite)
* **Язык программирования:** Python 3.13
* **Библиотеки анализа данных:** Pandas, NumPy
* **Визуализация:** Matplotlib, Seaborn
* **Статистика и ML:** SciPy (`scipy.stats`), Scikit-learn (`sklearn`)
